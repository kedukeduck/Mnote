# Mnote Android 1.0.5-test：悬浮摘录体验修复

- 包名 `com.codex.mnote`，versionCode `6`，测试签名与 1.0.4-test 一致，可覆盖安装，不要卸载旧版。
- 本次没有修改或部署服务端运行代码，也没有增加系统权限。

## 修复内容

1. **截图工具不再有整块底色**：选区阶段的面板、按钮、工具芯片均为透明背景，文字增加阴影保持辨识；操作区压缩为两行，取消 / 收起 / 下一步与圈选 / 画笔 / 标记 / 撤销 / 全图 / 移位分组。仍支持工具移到顶部，按钮自身仍占触控区域，不宣称控件完全不遮任何像素。
2. **想法页顶部选区预览**：预览显示实际裁剪和笔迹，背景保留淡化场景；表单不再靠全屏背景图充当预览。输入框移到表单最前，正文 / 链接仍能滚动。
3. **键盘避让**：同时处理 `WindowInsets.Type.ime()` 与可见窗口区域变化。按键盘顶部的屏幕坐标约束表单，在系统已经缩小窗口时不重复扣减键盘高度；聚焦输入框主动请求滚动到可见区域。
4. **来源识别补充读取路径**：磁贴启动透明过渡页之前读取本次来源快照；截图前的当前来源优先，读取为空时才采用 2 秒内点击快照。处理厂商将快捷设置暴露为应用窗口的情况；窗口列表不可用时补充活动根节点读取；地址栏失败不再导致已知应用包名丢失。
5. **保存反馈**：悬浮编辑本地保存成功 / 失败均显示 Toast；失败保留可编辑会话。无效链接和准备图片失败也有提示。普通编辑页保存错误同样补充 Toast。成功表示已经写入本机，不代表已完成云端同步。

## 升级与使用

- 正在编辑的记录请先保存，再覆盖安装。
- 如来源仍不可用，先保存未完成会话，再在系统辅助功能关闭并重新启用“Mnote 单次摘录”，确认允许查看屏幕内容。此能力来自 1.0.4 的权限声明，不能由应用绕过系统授权。
- 本版不增加浏览历史 / 输入 / 通知监听。恢复已有悬浮会话不重新读取来源，过期快照不会被当成当前应用。
- 浏览器地址栏仍仅适配 Chrome、Edge、Brave、Firefox 家族，具体版本可能隐藏地址或改变控件。普通 App 内部页面 URL 仍需分享 / 粘贴，不能保证自动获取微博动态链接。
- 未保存的悬浮会话仍是内存会话；系统杀进程、停用无障碍或重启可能丢失，请及时保存。

具体测试数量、lint 结果、源码提交、APK 哈希和签名见 `release-manifest.json`。界面图片是原生 View 测试渲染，使用虚构内容；IME 测试注入了键盘占位，并非实机输入法截图。

当前没有连接用户手机，无法从其日志确认“来源一直未知”的唯一实机原因，也不能承诺所有厂商悬浮窗 / 输入法均已实测。需要在实际手机验证来源包名、浏览器网址、键盘避让和 Toast；若仍异常，请提供手机型号、Android 版本、浏览器名称与版本，以及不含私密内容的录屏。
