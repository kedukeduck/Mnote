# Mnote 1.23.0-test · 后台文字稿

- 添加分享链接时可选择是否「解析音频」，默认只保存链接，不获取音频。
- 开启解析并确认声明后，任务先持久保存到本机队列，立即返回记录页。可以继续编辑、保存或与 AI 聊天，不再等待文字稿完成；关闭记录页不会取消已创建的任务。
- 完成或失败后发出结果通知。Android 在「设置 → 解析任务」查看，Windows 在「设置 → 音视频解析」查看，支持进度、失败原因、完整结果、复制、重试和取消/删除。
- 服务端独立收集并归档结果，已归档的历史和文字稿按账号读取，不依赖手机一直打开或停留在解析页。
- 文字稿与记录关联，但不会自动覆盖摘录。确认导入后才修改摘录，保留想法、原文、截图和标签，并继续标记为未核验的自动转写内容。Windows 先导入编辑草稿，再由用户保存。
- 删除解析任务不会删除记录或已导入的摘录。重试失败任务需重新确认声明；不重复创建编号相同的提交。

Android 需允许任务通知；拒绝通知不影响服务端解析和历史查询。系统省电、强制停止或网络不可用可能延迟手机通知；Windows 完全退出后需再次启动才能收取任务提醒。后台转写仍有平台公开访问、时长、大小、队列和提交额度限制，不绕过登录或访问保护。

已有旧版客户端已删除的临时任务无法追溯恢复。新机制将保留升级后的已归档任务，容量满时明确提示清理，不会静默删除旧结果。
