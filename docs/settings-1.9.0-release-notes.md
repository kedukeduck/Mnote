# Mnote 1.9.0-test · 简洁导出与统一设置

- Android / Windows：导出入口改为“选择导出”，延续 A「轻盈极简」风格；卡片显示记录摘要、日期、标签与勾选状态，底部明确显示选择数量和导出操作。
- Windows 直接点击即可多选，不再需要按 Ctrl；Android 小屏可滚动列表，保存入口固定在底部。
- 首页右上角新增“设置”，统一管理“账号与同步”和“版本与更新”。
- 最新版本信息、APK、Windows 安装包 / 便携包直接由 Mnote 自有服务器提供。GitHub 仓库转私有后，1.9.0 及以后的客户端不受影响；不用填写更新 URL 或 Token。
- 保留 HTTPS、固定下载来源、文件大小与 SHA-256 校验，Android 额外校验包名、版本与原签名。不自动安装或降级。

先覆盖安装此版本，再把仓库设为私有。1.8 及更早的客户端仍只认识 GitHub，仓库已经私有时请在 https://chenyu.online/heartnote-capture/updates/ 手动下载安装。

原有 Markdown 内容结构、图片分享确认、可撤销图片链接、账号隔离和同步规则不变。安装前保存草稿，覆盖安装，不要卸载旧版。Android 延用原调试 / 测试签名；Windows 为未签名 x64 测试包。自动化测试不能替代真实设备试用。
