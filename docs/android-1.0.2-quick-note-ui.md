# Mnote Android 1.0.2-test：随手记与轻量界面

- 包名：`com.codex.mnote`
- 版本：`1.0.2-test`，versionCode `3`
- 发布标识：`mnote-android-v1.0.2-test`
- 变更范围：Android 客户端；没有修改 Windows、同步服务或已有记录格式。

## 本版变化

### 两个独立快捷按钮

- **随手记**：从其他 App 下拉快捷设置，点击后直接进入纯文字编辑页，默认“想法”，可切换“评论 / 想法 / 待办”。不请求截图、不生成图片附件、不要求无障碍权限，可以离线保存。
- **单次摘录**：保留 1.0.1 已修复的跨应用截图流程，截取当前画面后进入截图批注页。截图仍需要 Android 11 及以上和用户主动启用无障碍服务。
- 两个入口均可从首页“快捷按钮与截图设置”添加。Android 13 及以上使用系统添加提示；较早版本或不支持提示的厂商系统，可手动编辑下拉面板添加。
- 随手记使用单独的不可变 PendingIntent，适配 Android 14 / 15 的启动方式，创建新编辑任务，不清理已有编辑页。锁屏时先解锁。

### 编辑体验

- 纯文字页移除隐藏截图框原先占据的空间，改为完整书写区域，主动聚焦并请求打开键盘。
- 分类改为分段选择控件，保存按钮固定在顶部。
- 空白记录不允许保存；空白页直接退出，已经输入内容则仍需要确认放弃。
- 截图页保留圈选、画笔、荧光笔、撤销和全屏工具。保存仍分别保留原始裁剪、批注图片、来源文字和本人评论。
- “待办”只调整显示名称，底层仍保存为 `todo`；本版没有新增提醒或完成状态功能。

### 界面

- 浅灰背景、白色圆角卡片、黑灰文字、少量蓝色强调，替换旧紫色描边风格。
- 首页优先展示快速记录与最近内容，系统截图设置可展开；同步入口保留在页首。
- 列表减少内部术语，完整来源、保真度和 AI 策略仍在详情中保留。
- 同步设置沿用现有加密与安全窗口，改为分组表单；地址规则可以展开查看。
- Android 8.0 保留深色导航栏，Android 8.1 及以上适配浅色导航栏；圆角裁切用兼容旧版本的 View API。
- 本轮为浅色视觉改版，不包含全套深色主题。

## 原地批注的评估与边界

可以设计覆盖在来源 App 上方的编辑层，而不是普通 Activity 页面。Android 提供由已连接无障碍服务显示的 [TYPE_ACCESSIBILITY_OVERLAY](https://developer.android.com/reference/android/view/WindowManager.LayoutParams#TYPE_ACCESSIBILITY_OVERLAY)，是可评估的实现路径。

这不等同于获得系统截图编辑器权限，也不能直接修改其他 App 的内容。需要独立处理覆盖层关闭、键盘焦点、返回手势、屏幕旋转、服务断开和受保护窗口；不能据此保证所有厂商设备的行为相同。

本轮先保留用户已确认正常的截图链路，交付独立随手记和界面改版。**本 APK 没有新增原地悬浮批注，也没有新增 SYSTEM_ALERT_WINDOW 权限。** 后续若启用覆盖层，仍需重新说明实际权限用途，并保持用户主动触发、受保护画面不绕过的边界。

## 验证

运行：

```sh
./gradlew --no-daemon testDebugUnitTest assembleDebug lintDebug
```

- `CaptureTileFlowTest`：原有跨应用启动、焦点时机、服务连接与离开时取消，API 30 / 35 共 20 项。
- `QuickNoteFlowTest`：独立入口、无截图载荷、系统绑定权限、PendingIntent、无障碍关闭时写字、纯文字只写元数据、分类、空白校验、放弃提示与首页入口，API 30 / 35 共 14 项。
- `CaptureUiLayoutTest`：API 35 的原生 Skia 渲染，覆盖首页、纯文字页、截图页、同步设置；验证 1.5 倍字体及预留键盘空间后的输入区和保存按钮；同时验证截图保存仍生成两张图片并删除临时全屏草稿，共 5 项。
- `CaptureSyncPreferencesTest`：既有配置规则 5 项。
- 总计 44 项测试。APK 构建与 lint 作为发布检查；具体结果、源码提交与 APK 校验值附在 Release 的 `release-manifest.json`。

渲染预览在 `app/build/ui-previews/`，来源是真实 Android View 和虚构示例记录，**不是手机实拍，也没有真实用户内容或令牌**。预览未模拟真实系统状态栏、键盘和快捷设置面板。

本次没有连接 Android 实机，自动化结果不替代厂商系统、锁屏解锁、真实输入法和跨 App 返回效果的手机验收。

## 安装与验收

1. 下载 Release 中的 `Mnote-Android-1.0.2-test.apk`，直接覆盖安装，不要卸载旧版，以保留记录和同步配置。包名与测试签名沿用已有版本。
2. 打开 Mnote → “快捷按钮与截图设置” → 添加“随手记”。原有“单次摘录”可以继续使用。
3. 在浏览器或聊天 App 中下拉面板点击“随手记”，确认无需截图就能输入；分别保存想法和待办，并在 Mnote 首页查看。
4. 暂停无障碍截图服务后，随手记仍应可用；重新启用后再测试截图入口。
5. 回到其他 App 点击一次“单次摘录”，确认仍得到来源 App 的截图；圈选、批注、写评论、保存或取消后检查返回行为。
6. 检查旧记录和原同步配置仍存在，新增纯文字记录在已配置的同步服务中没有图片附件。
7. 在自己的输入法、大字体、横竖屏与锁屏解锁场景下复核；发现问题时提供手机型号、Android 版本与复现步骤。
