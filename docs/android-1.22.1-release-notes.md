# Mnote Android 1.22.1-test · 修复文字稿连接等待

记录 → 摘录 → 从视频链接解析文字稿。

- 修复重新登录后后台同步可能长期占用账号锁，使文字稿页面一直显示「正在连接解析服务」的问题。解析读取一次完整、账号绑定的凭据快照，不再排队等待整库同步；不会混用不同账号的服务地址和 Token。
- 给连接操作加入整体超时，覆盖 DNS、连接和响应读取；异常后明确显示重试入口，不无限转圈。无法立即中断的系统网络调用也受线程数量限制。
- 重连成功清除先前的登录或网络错误；明确提示登录过期，不再把它仅描述为「未登录」。
- 超时后忽略旧请求迟到的结果，避免覆盖新连接状态。提交不确定时沿用本次 UUID，由用户明确恢复，不会自动重复创建文字稿任务。

只更新 Android，Windows 仍为 1.22.0-test。服务端、已有笔记、账号密码和聊天数据均不修改。覆盖安装前保存草稿，不要卸载；沿用同一安卓测试签名。
