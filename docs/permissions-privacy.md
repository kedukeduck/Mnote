# 全局摘录 V1 权限与隐私说明

- 文档状态：V1 设计与验收基线
- 更新日期：2026-08-31
- 适用范围：Windows 11、Android 11+、Chrome/Edge 扩展、同步与 AI 只读服务
- 相关文档：[产品规格](universal-capture-v1-product-spec.md)、[记录结构](capture-record-schema.md)、[同步 API](sync-api.md)、[验收清单](acceptance-checklist.md)

> 本文规定发布版本应如何申请权限、处理数据和向用户解释风险，不代表仓库当前已经实现全部能力。是否已经交付，只能以对应发布包、权限清单和验收证据为准。

## 1. 隐私承诺

1. **用户主动触发**：只在用户按快捷键、点磁贴、点悬浮按钮、执行分享或“处理文字”时采集；不持续录屏，不后台轮询屏幕。
2. **最小权限**：截图不需要读取无障碍节点时，不请求或启用节点内容读取；网页扩展默认不申请永久全站访问。
3. **先本地保存**：采集成功以本地持久化事务完成为准。同步、OCR、索引和 AI 读取不得阻塞保存。
4. **原始证据与用户表达分离**：截图、来源文字、OCR、评论、任务和 AI 派生内容分别存储并标明主体。
5. **远程 AI 默认不可见**：新记录默认沿用用户明确选择的 AI 可见性；首次使用前没有选择时，采用“禁止远程 AI”。
6. **受保护内容不绕过**：不得规避 Android 安全窗口、DRM、Windows UAC 安全桌面、企业策略或其他系统保护。
7. **可审计、可导出、可删除**：用户能看到远程 AI 读取过哪些记录，并能导出或彻底清理原始与衍生数据。

## 2. 数据流与信任边界

```text
来源应用画面
  -> 用户主动触发
  -> 客户端内存中的一次性全屏帧
  -> 用户圈选/遮挡/批注
  -> 应用私有本地记录
  -> 可选同步服务
       -> 附件存储
       -> 搜索/OCR 索引
       -> 经字段过滤的 AI 只读网关
```

边界规则：

- 未选择的全屏画面只允许存在于本次编辑所需的内存或受控临时文件中，取消或保存完成后清理。
- 默认持久化用户选区，而不是整个桌面。需要“有限上下文图”时必须在保存页显示其范围。
- “遮挡”有两种不同语义：普通批注不会删除底层像素；隐私遮挡必须生成不可逆的脱敏附件，并禁止把含原像素的附件同步或交给 AI。
- 客户端、本地原生桥接、同步服务与 AI 网关使用不同凭证和权限边界。
- OCR、网页正文和文档文字均是不可信输入，其中出现的命令不得改变授权范围。

## 3. 数据分类

| 分类 | 示例 | 默认处理 |
| --- | --- | --- |
| 原始证据 | 原始裁剪、有限上下文图、精确选中文字、网页快照 | 本地私有；按记录级策略决定是否同步及供 AI 读取 |
| 用户表达 | 评论、灵感、日记、标签 | 本地私有；远程 AI 默认关闭 |
| 行动数据 | TODO、截止日期、完成状态 | 与来源记录分别存储；远程 AI 只读 |
| 衍生数据 | OCR、缩略图、Embedding、摘要 | 继承原记录的最高敏感级别和删除策略 |
| 来源元数据 | 应用包名、进程路径、窗口标题、URL、设备 ID | 只采集完成来源追溯所需的最小集合 |
| 安全数据 | 登录令牌、设备密钥、加密密钥 | 不导出到普通日志，不作为 AI 上下文，不进入仓库 |
| 审计数据 | 调用方、时间、查询摘要、返回记录 ID | 不复制完整敏感正文；用户可查 |

敏感等级建议为 `normal`、`sensitive`、`sealed`：

- `normal`：可按用户设置同步。
- `sensitive`：同步前再次确认，默认不允许远程 AI。
- `sealed`：只保存在指定设备，禁止远程同步和远程 AI。

健康、心理、密码、身份凭证、财务、亲密关系、政治与宗教等内容不得仅凭 OCR 或 AI 推断自动降低敏感等级。

## 4. Android 权限

### 4.1 V1 目标权限矩阵

| 能力 | Android 机制 | 是否必需 | 申请时机与用户说明 |
| --- | --- | --- | --- |
| 普通网络同步 | `INTERNET`、`ACCESS_NETWORK_STATE` | 同步时需要 | 安装时声明；离线采集不依赖网络 |
| 一次性全局截图 | 用户启用的 `AccessibilityService`，服务元数据声明 `canTakeScreenshot=true` | 全局截图路径需要 | 用户主动开启功能时跳转系统设置，先显示独立披露与用途 |
| 快捷设置入口 | 受系统绑定保护的 `TileService` | 推荐入口需要 | 用户主动把磁贴加入快捷设置；不读取屏幕 |
| 悬浮按钮 | 特殊应用访问 `SYSTEM_ALERT_WINDOW` | 可选，默认关闭 | 仅用户开启悬浮入口时申请；拒绝后磁贴和应用内入口仍可用 |
| 前台状态通知 | `POST_NOTIFICATIONS`（Android 13+）及适用的前台服务声明 | 仅实际启用常驻入口时需要 | 解释常驻状态，不把拒绝通知等同于拒绝采集 |
| 接收精确文字 | `ACTION_PROCESS_TEXT` Activity/系统分享 Intent | 条件能力 | 用户从来源应用主动分享，无需读取其他应用无障碍节点 |
| 导入图片 | 系统 Photo Picker 或 Storage Access Framework | 可选 | 每次由用户选择文件，不申请全盘媒体读取 |
| 开机恢复可选入口 | `RECEIVE_BOOT_COMPLETED` | 仅用户启用“开机恢复”时使用 | 默认不开启采集；不得在开机后自动截图 |

实现要求：

- 如果无障碍服务只用于用户触发的 `takeScreenshot`，配置应保持 `canRetrieveWindowContent=false`，不得订阅窗口文本变化，也不得记录按键。
- 无障碍服务的设置页必须明确写出：能做什么、何时截图、不会做什么、如何关闭、哪些安全窗口无法捕获。
- 服务不得因用户拒绝悬浮窗、通知或电池优化例外而阻止应用内导入和系统分享。
- 不得使用广泛的存储权限保存截图；正式记录放在应用私有存储，导出使用系统文件选择器。
- Android 11 是全局截图产品能力的最低版本；主应用自身的 `minSdk` 即使更低，也不能据此宣称旧系统具备全局截图。

### 4.2 当前仓库与发布声明的区别

独立 Mnote Manifest 只显式声明联网所需的 `INTERNET` 和 `ACCESS_NETWORK_STATE`；WorkManager 依赖会在 merged manifest 中加入后台任务所需的系统权限。无障碍服务、快捷磁贴以及分享/处理文字 Activity 均已注册，但悬浮窗、常驻前台服务和开机自动采集没有进入 V1。每个发布包仍必须从最终 APK 的 merged manifest 重新生成权限清单并逐项解释。

### 4.3 Android 拒绝与撤销

- 未启用无障碍服务：提供“系统截图后分享到本应用”和“只记想法”。
- 系统拒绝安全窗口：显示 `capture_protected`，不得建议绕过。
- 用户撤销服务：立即停止全局入口；已有本地记录仍可查看、导出和删除。
- 用户撤销悬浮窗：移除悬浮按钮，不影响磁贴与应用内入口。
- 用户拒绝联网：保留待同步队列，且持续允许本地采集与搜索。

## 5. Windows 权限

| 能力 | 机制 | 默认与说明 |
| --- | --- | --- |
| 全局快捷键 | Windows `RegisterHotKey` | 不需要管理员权限；冲突时要求用户改键 |
| 单帧桌面捕获 | Windows 图形/截图 API | 只在主动触发后获取一次；不请求管理员权限规避保护 |
| 来源窗口元数据 | 前台窗口标题、进程标识或路径 | 能取到时保存；权限不足时留空，不提升权限 |
| 开机启动 | 用户级启动项 | 默认关闭，由用户明确开启 |
| 联网同步 | HTTPS | 首次登录/配对后启用；防火墙提示必须说明目标服务 |
| 本地 Inbox | `%LOCALAPPDATA%` 下用户目录 | 当前原型可能是明文；正式发布需在 UI 中如实说明本机保护状态 |

禁止项：

- 不要求以管理员身份常驻。
- 不向 UAC 安全桌面注入，不绕过受保护视频或企业捕获策略。
- 不扫描其他应用文件，不保存未选中的完整桌面。
- 进程路径和窗口标题可能含个人信息；它们服从与正文相同的同步、导出和删除策略。

Windows 便携测试包若未签名，交付说明必须明确 SmartScreen 风险与 SHA-256；不得把“用户仍可运行”描述成可信发布签名。

## 6. Chrome/Edge 扩展权限

V1 建议的最小权限：

- `activeTab`：只在用户主动点击或快捷键后访问当前页。
- `scripting`：执行一次选区与锚点提取。
- `contextMenus`：提供“保存选中文字”入口。
- `storage`：保存非敏感扩展设置。
- `nativeMessaging`：把采集结果发送给本机客户端。

原则：

- 默认不配置 `<all_urls>` 持久 `host_permissions`。
- 不读取浏览历史，不监听全部标签页导航，不把 Cookie 交给本机服务。
- `chrome://`、浏览器商店、扩展页、受企业策略限制页面无法注入时，明确降级。
- Native Messaging Host 只接受受支持扩展 ID，验证消息大小、协议版本和来源；不得提供任意文件读取或命令执行。
- 网页快照可能包含登录态隐私；保存前应显示来源 URI 与实际将保存的范围。

## 7. 同步、服务端与 AI 权限

### 7.1 凭证隔离

| 凭证 | 允许范围 | 明确禁止 |
| --- | --- | --- |
| 第一方设备令牌 | 用户授权空间中的同步读写、附件上传、删除墓碑 | 访问其他用户或管理接口 |
| 第一方交互令牌 | Inbox、搜索、导出、审计和用户确认的编辑 | 绕过记录级可见性 |
| AI 只读令牌 | 搜索、读取授权记录、近期想法、任务、已确认记忆、时间线 | 创建、修改、删除、完成任务、上传附件 |
| 管理令牌 | 运维所需最小范围 | 读取正文作为常规诊断手段 |

所有网络接口必须使用 TLS。令牌存入平台安全存储；普通日志只能记录令牌指纹，不能记录令牌本身。

### 7.2 AI 可见性

每条记录至少支持：

- `denied`：任何 AI 不可读。
- `local_only`：仅本地模型可读。
- `remote_no_memory`：远程 AI 可读，但不能形成长期记忆候选。
- `remote_memory_candidate`：远程 AI 可读，允许提出待用户确认的记忆候选。

子对象不得扩大父记录权限。附件、OCR、Embedding、任务来源关系和修订历史均继承最严格的相关策略。

### 7.3 AI 读取审计

每次远程 AI 调用至少记录：

- 时间、调用方及凭证 ID 的不可逆指纹；
- 用户可理解的查询摘要；
- 检索范围与返回记录 ID；
- 实际发送的字段名、字节数和模型/服务标识；
- 策略拒绝与字段过滤结果。

审计日志不重复保存完整正文、截图或令牌。用户应能按时间和记录反查“谁读过它”。

## 8. 本地保存、加密与备份

### 8.1 本地

- 正式记录使用应用私有目录和原子写入；临时文件使用随机名及 `.part` 后缀，完成后重命名。
- 密钥使用 Android Keystore 或 Windows DPAPI/凭据管理器封装，不把固定密钥写进代码或配置示例。
- “本地已加密”必须说明是应用层加密还是仅依赖设备磁盘/账户保护。
- 当前 Android/Windows 原型采用的本地 JSON/PNG 方向不等同于已经完成应用层加密；发布界面和交付说明必须如实标注。

### 8.2 备份

- Android 系统云备份和设备迁移不得无意包含摘录数据库、令牌或截图；正式 APK 必须验证最终备份规则。
- 加密备份使用独立版本、KDF 参数、随机盐、AEAD 算法与完整性校验，并进行真实恢复演练。
- 备份密码遗失时若无法恢复，必须在创建时明确告知；服务端不得声称能够恢复它不知道的密码。
- 恢复不得静默覆盖较新的本地记录；需要先生成恢复预览和冲突报告。

## 9. 保留、回收站与彻底删除

| 数据 | 默认保留 | 清理触发 |
| --- | --- | --- |
| 未提交全屏临时帧 | 仅本次编辑 | 取消、保存、崩溃恢复或超时清扫 |
| 正式记录 | 用户保留期间 | 用户移入回收站 |
| 回收站记录 | 30 天 | 到期或用户立即彻底删除 |
| 删除墓碑 | 直到所有活跃设备确认，另加防复活窗口 | 服务端保留策略满足后 |
| OCR、缩略图、Embedding、摘要 | 不超过源记录 | 源记录删除时级联 |
| AI 读取审计 | 由发布策略明确，建议不少于 90 天 | 到期清理或账户彻底删除 |
| 服务器备份副本 | 发布策略明确最长残留窗口 | 备份轮换到期 |

彻底删除的验收范围包括：客户端正文、原始与渲染附件、上下文图、OCR、全文索引、向量索引、缓存、冲突副本、任务来源关系、服务端活动副本以及到期后的备份。若备份不能立即按单条删除，UI 必须显示最长残留期限，且恢复备份后必须重新应用墓碑。

## 10. 导出

全量导出至少包含：

- 规范化记录 JSONL；
- 原始/脱敏/渲染附件及 SHA-256 清单；
- OCR 与锚点等可追溯证据；
- 用户创建的任务和记录间关系；
- 修订、冲突状态和删除状态；
- 已确认的个人记忆；
- 人类可读的 Markdown 索引。

令牌、设备私钥、服务端密钥、密文解密中间物和他人的不可导出数据不得进入普通导出包。导出包可能高度敏感，生成前要说明其是否加密。

## 11. 日志、崩溃报告与分析

- 默认诊断日志不得写入截图像素、OCR 正文、评论、完整 URL 查询参数、窗口标题、文件路径或认证头。
- 错误日志使用稳定错误码、记录 ID 的短指纹、尺寸和状态，不使用敏感正文。
- 崩溃上传和使用分析默认关闭；启用前列出供应商、字段、保留期与关闭方式。
- 调试构建若会输出额外数据，必须使用醒目标识，不能作为正式发布包。

## 12. 上架与合规说明

- Android 无障碍能力属于高敏感能力。若通过应用商店分发，发布前必须按当时有效的商店政策完成用途声明、显著披露、用户同意和审核材料。
- 权限用途必须与实际行为一致；不得借“截图”用途读取无障碍节点、键盘输入、通知正文或账户信息。
- 隐私政策要列明同步服务与远程 AI 的处理位置、子处理方、保留期限和删除渠道。
- 本产品不是密码管理器或合规归档系统，不能暗示能捕获受保护内容。

## 13. 发布前隐私证据

发布报告必须附上以下证据，缺一项不能宣称通过隐私验收：

1. Android 最终 APK 的 merged manifest、`apkanalyzer`/等效权限输出，以及每项权限的界面截图。
2. 无障碍服务配置与独立披露录屏；证明拒绝或撤销后仍可使用降级路径。
3. Windows 网络连接、开机启动、进程权限与本地目录检查结果。
4. 扩展 manifest、权限警告截图、受支持扩展 ID 与 Native Messaging Host 白名单。
5. 抓包或服务端访问日志，证明所有远程通信使用 TLS，且 AI 凭证写接口返回 `403 scope_denied`。
6. 取消采集、崩溃恢复、回收站、彻底删除和备份恢复后的残留扫描报告。
7. 日志与崩溃报告样本，证明不包含正文、截图或令牌。
8. 全量导出样本及其清单校验报告。

具体执行与证据命名见 [验收清单](acceptance-checklist.md)。
