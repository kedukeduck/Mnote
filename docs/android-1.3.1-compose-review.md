# Android 1.3.1-test：A 方案的记录与阅读页

包名 `com.codex.mnote`，versionCode 16。沿用测试签名，先保存正在编辑的内容，再覆盖安装，不要卸载。账号、同步协议、记录格式与线上服务器保持不变。

## 记录

- 原地悬浮截图继续先圈选，再进入“记下想法”；顶部约 320dp 大预览，下面依次为预览切换、保留完整截图开关、来源链接、独立想法输入区和记录类型。
- “圈选区域 / 完整截图”切换只影响预览。完整截图展示选区轮廓，不改动截图资产、圈选坐标、画笔标记或保存范围。
- 保留上下文仍需用户主动开启。完整截图可能包含圈选外的信息，请在保存前确认范围。
- 进入想法页不再立即唤起键盘；点击输入后，悬浮预览随可用空间缩小，表单独立滚动。保留 IME 高度与可见窗口两种避让路径，避免系统已缩窗时重复扣除键盘高度。
- 文字摘录页采用大引用卡片、“摘录文字 / 原文”切换和独立想法区；没有取得原文时禁用原文预览，仍可手动补充。预览原文不会替换待保存摘录，也不会自动保留原文。
- 分享 / Activity 图片编辑入口保留原有圈选和画笔工具，改为预览在上、设置和想法在下的滚动结构。纯随手记仍把主要空间留给输入框。
- 已取得链接收为域名行，点击展开编辑；未取得时可手动添加，不改变自动获取能力。

## 阅读

- 详情由小弹窗改为全高度阅读界面，顶部固定返回和删除入口。
- 大截图预览可切换圈选内容与当时保留的完整截图，后者叠加选区轮廓；轻点图片可按宽度展开，便于阅读长截图，再点收起。
- 未保留完整截图时禁用相应切换，不伪造原始上下文。解码失败有提示，记录不被删除。
- 引用文字、自己的想法分别呈现；来源链接可点击返回原网页。时间、来源应用、同步状态、保真级别、AI 权限和完整 URL 收进“记录信息”。
- 删除继续经过确认、账号范围校验及原有同步删除流程；退出阅读释放预览位图。
