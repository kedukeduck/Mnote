# Mnote Android 1.19.0-test

- 分享图片采用统一的暖纸、墨绿与铜色排版：想法使用衬线字体并完整置顶，摘录以浅底引用块区分，图片仍在文字之后。
- 二维码收至右下角，面积比之前缩小约 30%；缩小页脚文字和装饰，保留扫码入口、静区与纠错。
- 保持实时模块选择、预览与保存一致、原文/来源只通过扫码页查看，以及长想法不截断。
- 扫码阅读页同步更新：所选模块页内导航、图片原图入口、可展开的原文和明确的来源域名；仅原文/来源的旧分享默认展开原文。
- 分享内容权限、历史有效链接及撤销规则不变。网页更新自动生效，安卓覆盖安装新版即可使用新分享图片。

本次仅发布安卓安装包，Windows 本机仍为 1.18.0-test；电脑打开扫码链接同样使用新版网页。Android 为保留现有签名的测试版，请保存草稿后覆盖安装，不要卸载旧版。

二维码经自动化原尺寸/部分半尺寸整图及全部组合定点识别验证；不同分享软件对图片的压缩和长图搜索方式不同，实机长按识别仍需实际使用确认。
