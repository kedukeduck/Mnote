# Mnote 1.11.0-test · 分享画廊与已有标签

## 分享管理直接预览

Android 和 Windows 的“分享管理”现在是历史图片卡片列表，打开即自动加载可见卡片的封面，不需要先点击条目。卡片显示分享时间、记录数量、图片数量与图片角色；优先展示批注图，没有批注图时展示首张历史图片。

沿用 A「轻盈极简」：浅灰底、白色圆角卡片、清楚的图片区与次级信息。Android 点击图片或“查看全部”进入大图，Windows 双击卡片或点“查看分享图片”。大图仍可切换同次分享的其他截图。

历史图片读取当次导出时的独立快照，不会重新导出或创建公开链接，也不依赖原记录仍在本机。已撤销的分享不再显示。撤销需再次确认，只撤销分享，不删除原始记录。

只按需读取可见卡片，使用有上限的内存缩略图缓存；离开页面不把新缓存落盘。断网或图片暂不可用时有明确提示：Android 可点提示重试，Windows 可点刷新重试。纯文字分享有说明，不显示空白图片框。

## 记录时选择已有标签

- Android：随手记、截图批注与记录编辑中的标签区增加“选择已有”。在当前页面内展开，支持搜索、勾选 / 取消、多选和分批显示。适用于无障碍悬浮记录，不额外申请权限或打开新窗口。
- Windows：新建与编辑记录的标签区增加已有标签下拉框，选择即添加，可以继续选择其他标签。重复选择不重复添加。
- 两端保留手动输入新标签，选择已有标签不会覆盖手写内容。单条记录仍最多 20 个标签，每个最多 32 字。
- 候选从当前账号在本机可见的非删除记录汇总，包含已同步到本机的其他设备记录；不混入访客或其他账号。若其他设备刚新增标签，请先刷新同步。只存在于已删除记录的标签不作为候选。

## 升级

在“设置 → 版本与更新”获取，或使用自有服务器的安装包覆盖安装。Android versionCode 26，沿用原测试签名；Windows 为未签名 x64 测试版。安装前保存草稿，不要卸载旧版。无需数据库迁移、重设账号或重启服务端。
