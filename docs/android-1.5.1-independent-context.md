# Android 1.5.1-test：独立页面上下文与返回稳定性

包名 `com.codex.mnote`，versionCode 19，沿用上一版调试 / 测试签名。保存未完成的草稿后覆盖安装，不要卸载旧版。

## 使用变更

- 随手记的“同时保留页面上下文”始终可用，不再要求开启“摘录剪贴板第一条”。点击“读取页面文字”或“保存页面截图”仍是独立的主动采集动作；不增加任何默认读取。
- 关闭剪贴板摘录只清除摘录文字，不移除上下文；“移除页面上下文”只清除原文 / 页面截图，不影响想法或剪贴板摘录。
- 支持只保存页面原文或截图，不强制填写想法、链接或摘录。原文仍在上下文字段中，不复制成摘录。首页为仅原文记录提供可读摘要，并纳入摘录筛选及本机搜索。
- 页面文字和截图仍二选一。无障碍未启用时无法附加页面上下文，但可继续写想法或主动摘录剪贴板。截图仍需 Android 11+。
- “单次摘录”继续只截图；账号、同步地址、AI 权限和已有记录不变。

## 返回异常的处理

未获得手机错误堆栈，因此不能把某一项推断为该设备闪退的唯一原因。本次修正了共享路径中可以由代码确认的风险：

1. 将窗口 / 页面无障碍查询和截图预览解码移到独立后台线程。单次系统调用阻塞时，界面线程仍可处理超时、取消和输入；不与本地保存共用线程，超时后仍可保存想法。
2. 临时窗口缩为 1×1 时，将整个编辑内容设为 `GONE`，而非仍参与排版的 `INVISIBLE`；不让长文本在一像素宽度下重新排版。恢复窗口后才填入页面文字，输入区限制可见行数但不截断内容。
3. 成功、失败、取消及销毁时明确移除本次等待 / 超时回调并取消后台任务；迟到结果必须重新检查请求编号、前台状态、账号与来源窗口，不能影响新的请求或已销毁页面。
4. 对提供器异常和预览解码失败进行降级提示及草稿清理。未显示的后台图片可释放；已经交给 ImageView 的图片只解除引用，由系统回收，避免渲染线程稍后仍使用已手动回收的位图。
5. 截图前后仍核对外部窗口和已识别 URL。旧页面、锁屏、密码、隐藏 / 敏感文字限制保持不变，不绕过系统保护、不自动转截图。
