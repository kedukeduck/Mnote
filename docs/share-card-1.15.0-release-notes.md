# Mnote Android 1.15.0-test · 每张卡片均可扫码查看本次分享

## 卡片和扫码页面

- 每张新生成的分享卡片都包含二维码，包括纯想法、纯摘录或纯图片。二维码移至底部右侧，左侧为“扫码查看本次分享”，使用留有白边的 248 px 方码；想法仍在最上方、图片仍位于文字之后。
- 扫码页按本次勾选展示想法、摘录、圈选截图、页面截图、原文与来源。未勾选的模块、标签、记录时间和其他记录不会自动公开。
- 扫码页保留所选模块的完整内容，即使卡片中的摘录被截断或页面截图只显示局部；保存前明确提示这一范围。圈选图只保留当次实际选择的原图或批注图，不额外公开另一版本。
- 图片可以点击查看原图；分享管理也能查看这次公开的文字及图片快照。编辑或删除原记录不会改写已发出的分享；撤销会同时停用页面和图片链接。

## 保存与升级

预览和勾选不发布内容。首次保存需明确确认，联网创建所选内容的快照后再写入相册；没有登录、记录尚未同步或发布失败时，不会保存带失效二维码的卡片。已发布的同一份卡片可重复保存，不重复创建链接；更改分享模块后重新确认并生成新链接。

旧二维码维持原来授权的范围，不会自动增加内容；需要重新生成分享图片。升级恢复的旧预览也不会复用旧公开链接扩大权限。

Android `com.codex.mnote`，versionCode 31，沿用测试签名。请保存草稿后覆盖安装，不要卸载旧版。服务端升级为 0.7.0，兼容旧版仅原文/来源的卡片及 Markdown 分享；Windows 仍为 1.12.0-test。
