# Mnote 1.22.0-test · 链接文字稿摘录

记录页的「摘录」模块保留原有「读取剪贴板第一条」，增加「链接解析视频文字稿」。安卓和 Windows 复用已部署的 B 站、抖音文字稿服务，不需要额外填写转写服务器或 Token。

## 使用

1. 登录 Mnote，打开记录页并启用「摘录」。
2. 点击链接解析入口，粘贴视频链接，或包含链接的整段分享文字。
3. 选择内容权利依据、填写说明并主动同意声明，然后开始解析。
4. 等待解析与转写，检查文字稿后确认导入摘录。之后可继续编辑，与自己的想法、截图一起保存。

解析失败、取消或返回时不清空原有摘录、想法和截图。来源链接独立选择，不会自动声称当前截图来自视频。只在明确导入后更新摘录，不会自动保存记录或发送给聊天模型。

## 边界与隐私

- 支持当前服务可公开访问的 B 站／抖音视频及允许的直接媒体链接，不保证平台上的所有链接都可用。图文作品、需登录、验证码、付费或受保护内容不尝试绕过。
- 链接会发送到 Mnote 服务端；服务端获取临时媒体并进行语音识别，不要求手机一直播放。文字稿可能有错字、漏字和说话人识别不足，请核对后使用。
- 单个媒体最长 30 分钟、最大 80 MiB；摘录上限 10 万字，超出不静默截断。
- 使用现有 Mnote 账号授权，转写密钥只保存在服务器。未登录不能调用；一个账号不能读取、取消其他账号的任务。旧版 read/write/AI Token 和公开分享不具备转写权限。
- 临时转写结果按服务策略保留，当前为 24 小时；取消或导入后尝试清理任务。正式保存到笔记的摘录遵循原来的本机保存、账号同步和删除规则，不随临时任务过期而消失。
- 防滥用限额：每账号每小时 3 次、全体客户端每天 40 次、每账号同时 1 个任务。已被接受的任务即使失败或取消仍计入限额；明确告知的输入校验失败不占用解析配额。
- 权利声明是用户声明，不是服务端已验证授权，也不是对第三方内容的授权。

直接覆盖安装即可，升级前先保存草稿，不要卸载旧版。Windows 为未作 Authenticode 签名的测试版；安卓沿用现有测试签名。
