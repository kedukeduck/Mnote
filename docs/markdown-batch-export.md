# 批量导出 Markdown · 1.8.0-test

## 用户流程

Android：首页按搜索、标签或类型筛选 →「批量选择 · 导出 Markdown」→ 勾选 / 全选 → 确认图片分享 → 系统文件保存位置。Windows：首页筛选 →「批量导出 Markdown」→ Ctrl 多选 / Shift 连选 / 全选 → 确认分享 → 选择 `.md` 保存位置。

两端均提供「管理导出图片链接」，列出当前账号的有效导出，确认后可撤销某次导出的全部图片。不是删除笔记，也不能收回已导出的文字和已下载的图片。

首版要求账号登录且记录已同步。未同步、同步冲突、回收站、`ai_access=deny` 记录不可导出；`local_only` 可以通过此次明确的用户操作导出，不修改原来的 AI 权限。最多 100 条，超过时不自动截断。首页过滤范围不受首页分页显示条数影响。Windows 使用当前过滤结果，Android 在账号目录中重新应用相同过滤条件。

## 文件内容

一个 UTF-8 `.md` 文件，不使用 ZIP 或 Base64 内嵌图片。两端共用服务端格式，按创建时间从早到晚排序，同时间按稳定记录 ID 排序。

1. 文档说明：记录快照的用途、各字段含义、缺失状态、给 AI 的阅读说明和分享边界。
2. 导出范围：格式版本、导出编号、时间、选择说明、数量、排序与时区约定。
3. 记录索引：序号、记录 ID、创建时间、类型、标签。
4. 每条记录：基础信息与修订号、我的想法、外部摘录、实际保留的原文、来源应用/页面/URL、完整截图/圈选原图/批注图，以及已记录的圈选位置元数据。

不把收藏当作认同；不把外部原文当成用户自己的观点；原文完整性未知时明确标注，不宣称获取了完整页面。正文以引用块保留，不截断长原文。来自记录的 Markdown / HTML 特殊字符转义，避免正文伪装成章节或额外图片请求。

图片链接不等于 AI 已经看过图片。目标 agent 必须支持联网与视觉读取；导出内明确要求实际打开相关图片、引用记录编号，无法访问时如实报告。并不保证 ChatGPT 或任何其他软件自动遍历全部图片。

## 服务端协议与隐私

- `POST /v1/exports/markdown`：仅账号会话；请求 `records: [{id, revision}]`、`publish_images: true`、可选 `scope`。响应包含 `id`、`filename`、`markdown`、记录/图片数量。
- `GET /v1/exports`：仅返回本账号有效导出的 ID、时间、记录/图片数量，不返回图片令牌或其他记录。
- `DELETE /v1/exports/{id}`：仅该账号可撤销；令牌立即失效，随后清理本次快照图片，不触碰原始笔记。
- `GET/HEAD /s/{random-token}/{asset-name}`：只提供本次选中的图片，无记录查询/目录列举/元数据读取功能。256 位随机能力令牌，数据库只保存哈希；不包含账号写 Token。

每次导出在独立目录中复制图片并校验 SHA-256。之后编辑、删除原笔记，不会偷偷改变已导出的截图。持有链接无需登录；链接直到撤销或服务不可用，不承诺永久托管。发送 `no-store`、`noindex`、`no-referrer`，公开图片允许跨域，其他 API 和图片仍为私有。

创建前核对全部 ID、修订号和 AI 权限，再生成快照。遇到任意记录过期、被删除、越权、附件损坏或容量超限，整体失败，不生成部分 Markdown。文件选择取消时客户端尚未请求创建；文件写入失败后尝试撤销新快照，撤销失败明确提示到管理页处理。网络断开、进程被杀等造成响应丢失时，可能仍存在有效快照，可以在管理页撤销。

限制：每账号最多 50 次有效导出；每次图片累计 128 MiB，Markdown UTF-8 最大 6 MiB，完整 JSON 响应最大 8 MiB，超限明确拒绝，不静默截断。撤销旧导出释放有效次数额度。进程在目录提交与数据库提交之间崩溃可能遗留不可公开访问的孤立目录，需运维核对数据库后清理；当前不自动扫描删除目录。

## 部署与兼容

需要 Capture Server 0.3.0，环境变量 `MNOTE_PUBLIC_BASE_URL` 为外部可访问的 HTTPS API 根地址，例如 `https://chenyu.online/heartnote-capture`。代理应将同一前缀下的 `/s/` 转发到 API，并继续关闭包含 URL 的访问日志。未配置时带图导出被拒绝；不降低为 HTTP，也不自动公开原资产接口。

数据库新增在现有数据根目录的 `markdown-exports/exports.sqlite3`，不改现有账号或记录表。回滚到旧服务器版本后私有同步仍可用，但公开分享路径不再提供。上线仅重启捕获 API 服务，先备份虚拟环境、配置和数据，不修改 SSH 或网络规则。

Android 22 / 1.8.0-test 仍使用原测试证书；Windows x64 1.8.0-test 未签名，安装版/便携版均支持。上一版内置的更新入口可获取该版本。
