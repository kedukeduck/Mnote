# Mnote 1.16.0-test · 私人刊物

Android 和 Windows 采用统一的暖白、墨绿与铜色视觉，突出想法和记录本身。

- 首页默认全部记录，支持搜索、类型/标签筛选和原地多选删除、导出。
- 优化随手记、截图编辑和连续阅读，修正小屏输入、焦点恢复及收起字段的校验提示。
- 设置统一管理账号同步、历史分享、版本更新与快捷方式权限。
- Windows 增加侧栏、记录列表及连续阅读三栏布局。
- Android 每张新分享卡片均带二维码，扫码查看本次明确勾选的完整内容；未勾选内容不公开。旧分享不会自动扩大范围，需重新生成卡片。

请先保存草稿，再覆盖安装，不需要卸载旧版。Android 沿用原测试签名；Windows 为未签名测试包。1.9 及之后的测试版可通过自建服务器检查更新，1.7/1.8 如仍使用旧更新源，请从下载页手动覆盖升级一次。
