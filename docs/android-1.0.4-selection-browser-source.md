# Mnote Android 1.0.4-test：先选区，再写想法；自动来源识别

- 包名 `com.codex.mnote`，versionCode `5`，与 1.0.3-test 相同测试签名，可覆盖安装。
- 本次为 Android 增量版本，未修改或部署服务端运行代码。

## 交互

1. 在来源 App / 浏览器点击“单次摘录”，等待快捷设置收起后截图。
2. 冻结画面铺满悬浮窗口，先拖动框选，或用画笔 / 荧光笔批注；也可直接保留全屏。此时不出现想法表单。
3. 底部仅保留轻量工具条。横向滑动工具条可见“工具栏置顶”，方便选择画面底部；也可移回底部。
4. 点击“下一步”，从底部展开想法卡片。普通竖屏卡片高度限制在可用空间约 60% 内；小窗口、横屏或键盘占位时允许使用剩余空间并滚动输入。
5. 可查看 / 修改来源链接、选择分类、写想法，然后保存。“重选”返回截图选区，保留截图、笔迹、想法和链接。

整个截图流程仍基于无障碍悬浮窗口，而非直接编辑第三方 App 的真实页面；差别是第一步只显示全屏冻结截图与轻量工具条，不再把截图压成表单里的小预览。底部表单展开后不能误画截图。收起恢复保留当前步骤，不重新采集来源或截图。

原生选中文字的入口继续保留：在来源应用选中文字后，选择系统“记到 Mnote” / 分享给 Mnote，再写想法。本版没有在截图上增加 OCR 选字，不能让原本不支持文字选择的 App 获得原生选字能力。

## 自动来源：范围与边界

- 仅主动新摘录时读取一次来源应用包名；详情尝试显示本机可查询到的应用名称，无法查询名称时保留包名，不申请所有安装包查询权限。
- 浏览器地址栏适配：Chrome（含 Beta / Dev / Canary）、Edge、Brave、Firefox（含 Beta / Fenix）。这是控件适配范围，不是所有浏览器版本 / 厂商手机的实机兼容承诺。
- 只查询对应包名下的已知地址栏 view ID，不遍历正文、广告或聊天记录，不点击地址栏或菜单，不自动复制，不监听浏览历史和无障碍事件。
- 地址栏不可见、正在聚焦编辑、节点为密码、出现不同地址或没有合法地址时，保留来源应用但不给出猜测链接。不会沿用上一次截图的网址。
- 显式 HTTP(S) 保留路径、查询和片段；浏览器省略协议时补全 HTTPS，并单独记录 `browser_address_bar_https`，界面提示用户核对。显式地址记为 `browser_address_bar`。
- 浏览器可能只暴露域名、隐藏工具栏或改变控件 ID。读取到地址栏不等于总能获取完整原文 URL；请展开来源链接核对，必要时用浏览器分享完整链接补充。对带省略号的地址不做补全。
- 微博等普通 App 自动保存应用标识，但本版不支持可靠获取其任意内部动态页链接。仍可收起、复制原帖分享链接、恢复并粘贴。
- 只接受 HTTP / HTTPS，不执行 `intent:` 或自定义协议。打开链接由系统浏览器 / App Link 处理，不能保证恢复历史页面、登录状态、滚动位置或已删除内容。

## 权限变化和升级

为了读取来源应用 / 浏览器地址栏，无障碍元数据从 `canRetrieveWindowContent=false` 改为 `true`，并开启交互窗口 / 控件 ID 能力。运行时不订阅任何无障碍事件，来源对象不持有窗口节点，只随当前截图会话保存应用标识与 URL。

系统设置说明和启用对话框已更新用途披露。**升级后若来源仍未知，请先保存所有未完成记录，再去系统辅助功能关闭并重新启用“Mnote 单次摘录”**，以便系统重新加载能力。拒绝 / 无法读取来源不阻止截图保存；纯文字随手记和系统分享仍可使用。

剪贴板仍只在点击“粘贴”时读取。来源 URL 和应用包名遵循记录原有同步及 AI 可见性策略。未保存的收起会话仍只在内存中，服务关闭、系统杀进程、重启可能丢失，务必及时保存。

## 验证

```sh
./gradlew --no-daemon testDebugUnitTest assembleDebug lintDebug
PYTHONPATH=capture-server/src python3 -m unittest discover -s capture-server/tests -v
```

新增 / 更新回归覆盖：两步切换、全屏画布、工具条避让、重选不丢内容、选区尺寸、自动来源保存与同步、地址栏控件过滤、无事件读取、透明桥接窗口、遮挡窗口边界、拒绝猜测多链接和失效地址。

Release 的 `release-manifest.json` 记录具体测试数量、lint 结果、签名、源码提交与 APK 哈希。预览图来自原生 View 测试渲染，使用虚构页面，不是手机实测。当前环境未连接 Android 实机，需在用户手机验证：浏览器地址栏实际暴露内容、升级重授权、全面屏 / 刘海 / 手势、输入法、横竖屏、后台恢复和回跳。

技术参考：[Android 无障碍服务的窗口读取能力](https://developer.android.com/reference/android/accessibilityservice/AccessibilityServiceInfo)、[按控件 ID 查询节点](https://developer.android.com/reference/android/view/accessibility/AccessibilityNodeInfo)。
