# Mnote 1.16.0-test · 私人刊物 UI

用户已选择第三张「私人刊物」视觉，随后选择 A 开始实施。此版本直接改造原生 Android / Win32 应用，不是独立网页原型。

## 统一视觉

暖白 `#F7F4EC`、墨绿 `#24494E`、正文 `#242B2B`、辅助文字 `#666C66`、暖铜章节文字 `#955530`、素材底色 `#EFEBE3`、细线 `#DDD8CD`。Mnote 品牌字使用衬线，中文内容使用系统无衬线。手机触控目标至少 48dp，正文随系统字号缩放；分享图片沿用先前确认的纸张排版。

Android 共用资源色名暂保留 `coral` 等兼容名字，值已改为墨绿；新增 `JournalUi` 统一原生页头、细线、分节、主要动作。`bg_material_tab` 表示外部摘录，不给所有控件加装饰标签。

## 主要交互

- 首页默认全部记录；想法为主、真实小缩略图为辅，无图不生成占位图。日期分组，不常驻标签导航。
- 类型与标签在筛选面板里暂存，确认后应用；取消不改变当前结果。搜索仍覆盖想法、摘录、原文、URL 和标签。下拉或点击刷新；未登录本机刷新不强制跳转登录。
- 长按与选择导出进入同一原地多选，0 条不能删除/导出；全选只针对当前显示记录，最多100条。筛选剔除不匹配的选择；账号切换清空选择。
- 记录时先显示素材与想法，标签/来源/上下文默认收起。展开不会触发剪贴板或页面读取；必须继续明确选择。剪贴板关闭时仍可单独保留页面上下文。
- 详情连续展示想法、摘录、圈选截图、完整截图、原文、来源，不再通过切换预览隐藏原文。图片可打开独立大图；文本可选中复制。编辑不会改变附件或圈选坐标。
- 设置集中账号/同步、分享管理、更新，并新增快捷方式与权限、帮助与诊断入口。系统授权仍由 Android 处理。
- Windows 使用侧栏、独立列表与连续阅读区；窄窗口隐藏右侧并保留查看/编辑入口。保留已有回收站，不虚构 Windows 分享卡片制作功能。

## 不变的数据与权限边界

本机保存、同步/冲突、删除、公开分享是独立结果。未上传内容必须保留；删除记录不自动撤销历史分享。预览、勾选和截图展示位置调整不发布内容；明确确认后才创建公开快照并保存。取消 Markdown 的系统保存位置选择不创建分享。

本分支接续先前未发布的全模块二维码快照：二维码页只展示本次实际勾选模块的完整快照，未选内容/标签/记录时间不扩张到公开范围。该能力需要服务端 0.7.0；本地验证不等于服务器已部署。

本轮扫码网页保持改造前的样式。当前缺少内置浏览器，尚未获得使用外部自动化浏览器的选择答复，因此未交付未经视觉验证的网页配色改动；不影响原生双端改造。

## 验证与发布

真实 Android View 的 Robolectric/Skia 截图在 `app/build/ui-previews/`，它们不是 Android 真机截图。Windows GUI 验证由 Wine / Xvfb 驱动真实 Win32 程序，不能替代 Windows 真机/DPI 验证。

本轮不自动改生产更新清单，不部署服务端，不声称未发布的 URL 可下载。测试包沿用现有 Android 测试签名 / Windows 测试安装流程；覆盖安装保留数据，不建议卸载。最终验证记录见项目根目录 `design-qa.md` 及本轮验证文档。

发布补充：上述为开发阶段边界。2026-09-28 用户明确选择发布后，已部署服务端 0.7.0 并发布双端 1.16.0-test，详见 `private-journal-1.16.0-publication.md`；未继续改动扫码网页的视觉风格。
