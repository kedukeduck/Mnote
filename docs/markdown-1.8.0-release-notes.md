# Mnote 1.8.0-test · 批量导出 Markdown

Android 和 Windows 均新增：首页筛选 → 批量选择 → 确认图片分享 → 保存一个 Markdown 文件。

- 文档说明、字段含义与 AI 阅读提示，导出范围和记录索引。
- 完整保留自己的想法、外部摘录、已保存的原文、来源和标签，不截断长文。
