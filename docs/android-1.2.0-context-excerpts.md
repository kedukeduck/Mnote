# Mnote Android 1.2.0-test：上下文、选区与想法

包名 `com.codex.mnote`，versionCode `10`；沿用调试 / 测试签名，保存编辑内容后覆盖安装，不要卸载。沿用已有账号，无需重新激活。

## 截图

圈选 → 下一步 → 勾选 **同时保留完整截图** → 写想法 → 保存。

- 勾选后分别保存完整截图、未批注的选区图和批注后的选区图；记录选区在完整截图中的坐标。编辑器缩小显示大图时，坐标会映射回完整截图尺寸，不把缩略图坐标当作原图坐标。
- 默认不勾选，继续只保存选区。勾选会保存并同步圈选以外的画面，可能包含其他个人信息，请先确认。
- 打开记录详情 → **查看完整截图与选区**；蓝框展示所选位置，不修改完整截图文件。
- 只支持新增记录；以前已丢弃的圈选外画面无法补回。完整截图是当时可见的一屏，不是滚动长截图。

## 文字

**直接摘录**：在支持标准文字菜单的应用里选中文字 → 更多 → **Mnote 摘录**。也可用系统分享，把文字交给 Mnote。在下方写想法后保存。

**原文内再选取**：把原文文本分享给 Mnote，在文字预览中长按选中一段 → **摘录这段**；可勾选 **同时保留提供的原文**。

**补充原文**：若来源应用只传来选中文字，点击 **补充 / 查看原文** 粘贴上下文，再决定是否保留。不会自动读取剪贴板；用户在输入框中自行粘贴。

安卓标准 `ACTION_PROCESS_TEXT` 传递的是所选文字，并不保证提供文章全文。原生应用自定义菜单可能没有此入口，可尝试分享文字；不支持选择 / 分享的应用仍使用截图。Mnote 不会自动抓取链接全文、不把片段冒充完整文章，也不因摘录而替换其他应用输入框里的选中文字。

文字原文、摘录文字、用户想法独立保存。原文来自系统分享时标记 `shared_text`，用户粘贴或修改时标记 `user_supplied`。提供的内容不保证就是整篇文章。已知选择位置直接保存；只能用文字匹配时，重复或未匹配的片段不伪造唯一位置。

## 同步与 AI 契约

| 内容 | 规范记录位置 |
| --- | --- |
| 用户想法 | `comment` |
| 摘录文字 | `source.text`、`evidence.exact_text` |
| 提供的原文 | `evidence.context.text.full_text`，含 origin / extent |
| 文字选区 | `evidence.context.text.start/end`，UTF-16 左闭右开偏移；match 表示确定性 |
| 完整截图 | `assets.context` |
| 选区图 / 批注图 | `assets.original` / `assets.annotated` |
| 图片选区 | `evidence.context.image.selection`，完整截图像素 left/top/right/bottom |
| 笔画坐标基准 | `evidence.context.image.editor_width/editor_height`，编辑位图像素 |

Android 私有 `record.json` 的 `captureContext` 对应规范 `evidence.context`。完整截图与普通截图同样经过同步、下载大小 / SHA-256 校验、账号隔离和删除流程。云端回读、离线缓存、旧本机数据导入均保留新增信息。缺少声明已保留的完整截图时，该记录不作为完整记录显示。

MCP `get_capture` 对 AI 可读记录返回规范元数据，并按 **上下文图 → 选区 / 批注图** 返回带角色说明的图片。原有 AI 可见性规则不变，`deny` / `local_only` 不会因为保留上下文而自动开放远程 AI 权限。引用原文始终是外部证据，不是给 AI 的指令。

## 边界与验证

- 原文补充输入最多 40,000 UTF-16 代码单元；系统传入文字超过 100,000 时拒绝本次导入，要求分段，不静默截断。元数据最多 512 KiB，单张附件最多 16 MiB；上传总请求仍受已有 32 MiB 限制。
- 未勾选时不保存完整截图 / 原文；临时原始截图继续遵循保存完成后清理和草稿过期清理机制。
- 无新增权限，不新增后台屏幕 / 剪贴板监听，也不扩展来源应用识别。
- Android 原生 View 自动化渲染不是实机截图；各品牌文字菜单入口、输入法和后台同步仍需实机验收。

自动化覆盖完整图 / 选区坐标、缩放映射、未勾选不落盘、上传及回读完整性、原文可选、文字偏移与来源、原应用文字不被改写，以及 MCP 图片顺序和 AI 隐私过滤。发布时同时执行完整跨端验证脚本和公网独立测试账号验证；具体结果见发布附件。

系统传参边界参考：[Android 源码中的文字处理入口](https://android.googlesource.com/platform/frameworks/base/+/e0938b8/core/java/android/widget/Editor.java)。
