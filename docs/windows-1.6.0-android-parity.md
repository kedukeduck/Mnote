# Windows 1.6.0-test：对齐 Android 1.6.0

## 功能

- 新增原生知识库首页：搜索、类型 / 标签 / 未分类筛选、刷新、同步状态、应用内查看 / 编辑、删除确认与回收站恢复。
- 同 Android 使用用户名密码登录 / 激活和默认同步服务。会话使用 Windows 用户级 DPAPI 加密，记录按服务器与账号隔离；自动上传、增量拉取、离线待同步、修订号冲突保护、附件 SHA-256 校验。
- 旧 Inbox 原样保留。旧记录和未登录记录须通过账号页面的明确导入操作才能加入当前账号，不会登录即自动上传。
- 单次摘录：Ctrl+Shift+F9，先圈选 / 自由笔 / 高亮 / 撤销，再填写想法；可选同时保留完整虚拟桌面截图及圈选位置。
- 随手记：Ctrl+Shift+F8，默认纯文字，可主动摘录剪贴板当前第一条文字。页面文字 / 页面截图上下文可独立选择，不依赖剪贴板开关。
- 记录与阅读采用 A 风格配色和原生控件，大图预览、想法 / 摘录 / 原文独立编辑、长文内滚动、固定保存操作区、未保存提示；图片支持切换批注图 / 原图 / 完整截图、缩放和平移。
- 应用名自动识别；浏览器地址栏链接尽力识别，保留手动输入。页面正文只在主动选择后读取，独立辅助进程限制时间，超时后编辑器仍可用。上下文与摘录关系明确标为未验证。
- 默认保持 `local_only` AI 权限。逐条记录可调整权限，允许远程 AI 需显式确认；不会因账号同步自动开放远程 AI。
- 保存 / 失败使用应用轻提示和系统托盘通知，关闭窗口后保留托盘入口。

## 安全与数据兼容

保留 `schema_version: 1`、记录 ID、原始附件、未知字段、Android 截图坐标。Windows 新截图明确标记完整图、裁剪图及笔迹各自坐标系。编辑只修改可编辑字段，不用新 ID 替代已有记录。

HTTPS 证书正常验证；仅本机 / 数字私有 IP 可用 HTTP。请求禁止重定向；附件走固定同源角色路径，不使用远端返回的外站 href。账户变化时旧后台任务不可写入新账号。本机保存和同步分别在后台执行，网络不阻塞编辑界面。

记录本身不是端到端加密。未保存草稿不保证在强制结束进程或断电后恢复；正常保存 / 取消会清理本次临时图片。备份应退出应用并复制整个 `%LOCALAPPDATA%\PersonalCapture`。

## 验证

- Windows MinGW x64 编译，固定依赖哈希校验，无额外 MinGW 运行时 DLL。
- 数据层 60 项检查：Unicode、标签、原文匹配、DPAPI、账号隔离、导入、编辑冲突、删除、附件校验、异常 JSON、权限和类型编辑等。
- 两个独立 Windows Library 实例连接临时真实 Capture Server：激活、登录、上传、拉取、PNG 字节一致性、清空标签、编辑、删除、恢复、退出。
- Wine GUI 驱动真实圈选和笔迹、两步记录、完整上下文、标签过滤 / 未分类、长原文保存、删除 / 恢复、显式剪贴板、独立截图上下文、账号导入及同步。文字读取允许不支持环境下安全失败，不伪称所有浏览器已验证。
- NSIS 原生 x64 安装器：安装 / 覆盖安装 / 卸载 / payload 字节一致性 / 旧数据保留。
- `scripts/verify-mnote-v1.sh`：Android 编译、429 项单元测试和 lint，Windows、浏览器扩展、Capture Server 22 项测试（含 MCP）及 Android Manifest 检查通过。Android 代码与发布包未在本轮修改。
