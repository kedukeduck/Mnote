# Mnote 1.10.0-test · 看见图片，原地多选

- Android / Windows 延续 A「轻盈极简」风格：导出选择页展示真实截图缩略图，可打开大图预览。Android 按批注图、圈选原图、完整页面分别展示；Windows 大图保留角色切换及缩放。
- 首页长按记录进入原地多选，点击其他记录继续选择，底部显示数量，可批量删除或导出 Markdown。Windows 另支持右键和“多选”入口。每次最多 100 条；取消 / 返回（Windows Esc）退出多选。
- 从首页多选进入导出时，只带入明确选中的记录；未同步或不具备导出权限的内容不可导出。修改筛选会移除不再匹配的选择，切换账号退出多选。
- 删除前确认数量，完成后提示结果。Android 先校验全部记录，再一次性写入删除队列；Windows 按记录保存删除状态，若有失败会报告成功和失败数。账号删除联网后同步，服务端回收站保留恢复能力；Android 未登录记录仅从本机列表移除。
- Markdown 保留标准图片语法，并为每张图片补上“打开原始图片”链接。预览只读本机图片，不会发布分享；只有确认导出时才创建可撤销图片链接。Markdown 阅读器 / AI 必须能访问远程图片，纯文本读取无法自动获得图像内容。

安装前保存草稿，覆盖安装，不要卸载旧版。Android 延用原测试签名；Windows 为未签名 x64 测试包。通过设置中的“版本与更新”获取更新，安装包继续由自有服务器提供，不依赖 GitHub 仓库公开状态。
