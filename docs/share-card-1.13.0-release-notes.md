# Mnote Android 1.13.0-test · 一屏分享卡片

## 使用

打开一条记录，点击顶部“分享”。勾选需要的模块，预览实时重排，点击预览可放大；“保存到相册”保存的就是当前预览图。

可选模块：摘录、我的想法、圈选截图、完整截图、原文二维码、来源二维码。圈选截图有批注版本时，可以选择是否保留批注。不存在的模块置灰。

卡片采用已确认的暖纸色、宋体摘录和陶土色细线样式，缩小引号，不绘制标签、记录时间、记录类型和截图类型标题。统一输出 1080 × 1920 PNG，自动调整字体和图片空间，保持截图比例、不裁剪截图。不足以完整容纳的长文明确提示，不静默截断；长页面截图在一屏内会缩小。

## 原文与来源

页面原文和来源链接不直接排在图片上，通过一个真实二维码查看。两者可以独立选择；落地页只公开被选中的字段，不自动公开想法、摘录、标签、截图或整条记录。来源目前支持 HTTP / HTTPS 链接。

勾选和预览不会联网发布。保存带二维码的卡片前，会明确确认匿名可读的范围。二维码需登录且该记录已同步；不带二维码的卡片无需发布，可本机保存。二维码的目标是当次不可变快照，不会随原记录的后续编辑、删除而改变。

带二维码的分享可在“设置 → 分享管理”查看其文字快照、撤销链接；卡片 PNG 只保存在相册，不上传到分享管理。公开分享共用现有 50 项上限。撤销不能收回已经保存的图片或文字。截图像素中已有的私人信息不会自动打码。

相册写入失败会清理本次未完成图片，并尝试撤销本次新建二维码；网络导致撤销失败会提示到分享管理检查。重复保存已发布的同一张卡片不会重复创建分享。

## 升级范围

本次实现 Android 分享卡片和 Capture Server 0.6.0 的二维码落地页；Windows 客户端保持 1.12.0-test，尚未增加卡片制作入口。现有 Markdown 分享、同步与历史图片链接保持兼容，服务端不迁移数据库。

Android application ID 为 `com.codex.mnote`，versionCode 28，沿用原测试签名。请保存草稿后覆盖安装，不要卸载旧版。包内包含开源中文宋体及许可证，以保证不同手机上的摘录排版一致。此版本仍为测试版，非正式商店发行。
