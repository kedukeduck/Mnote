# Mnote Android 1.2.1-test：单次摘录优先读取选中文字

包名 `com.codex.mnote`，versionCode `11`；沿用调试 / 测试签名。先保存正在编辑的内容，再覆盖安装，不要卸载。账号、已有记录与同步服务不变。

## 使用方式

1. 在其他应用长按并选中文字，保持选区。
2. 拉下快捷设置，点击 **单次摘录**。
3. 如果来源应用提供可读选区，直接进入文字摘录页，写下想法后保存，不再截图。
4. 可选择 **同时保留提供的原文**；自动提供的仅是同一文字块，未必是整篇文章。可点 **补充 / 查看原文** 检查或修改。默认不勾选。

没有选中文字，或应用不提供选区时，继续原来的截图圈选流程。已有悬浮截图草稿时优先恢复草稿，不覆盖草稿。原有“只记想法”、文字菜单与系统分享入口继续保留。

## 为什么文字菜单可能没有 Mnote

是否展示 Android `ACTION_PROCESS_TEXT` 菜单由来源应用决定，部分应用使用自定义菜单。新版快捷入口不依赖这个菜单，而是在用户点击当下读取无障碍选区；若当下未取得，会在快捷面板收起后的透明过渡页再次读取，然后才截图。

前提是 Mnote 无障碍服务已开启并连接。部分浏览器、自定义阅读器或多节点选区不提供可用范围，或会在快捷面板打开时取消选区；本版不能保证这些场景成功，不使用剪贴板旧内容或 OCR 猜测代替选中文字。这些场景可继续截图，或由来源应用分享文字到 Mnote。

## 数据与隐私

- 不新增权限或文本事件订阅；只在用户点击时有界查询窗口节点，不后台记录选区、输入内容或导航历史。
- 只读取有效选区节点的文字，过滤密码、不可见及系统标记敏感节点；不向后搜索其他应用，不执行复制或修改选区操作。
- 系统快捷入口的 PendingIntent 不包含文字，仅携带一次性随机凭据；内容在进程内存中临时交接，绑定当前账号，五秒过期，消费、锁屏或服务销毁时清理。
- 选中内容与用户想法分别保存，`source_type=accessibility_selection`。可选原文标为 `origin=accessibility_node`、`extent=source_text_node`，保留 UTF-16 选区坐标，不冒充全文。
- 勾选保留的原文会跟随记录按既有账号和 AI 可见性策略同步；不勾选则不写入原文上下文。
