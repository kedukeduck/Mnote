# Mnote Android 1.0.6-test：云端刷新与截图工具设计

包名 `com.codex.mnote`，versionCode `7`。调试 / 测试签名与上一版保持一致；请先保存编辑中的内容，然后覆盖安装，不要卸载旧版。

## 本次改动

1. 首页“最近记录”旁增加 **刷新**：真正调用服务端变更接口，下载其他设备的记录和原图 / 批注图，按时间合并到列表。显示拉取中、成功、无新增、网络失败、凭证错误或需要继续刷新；重复点击不会启动并发拉取。原“同步全部”改名为“上传本机”，上传行为保持不变，不把缓存重新上传。
2. 截图工具重新设计：统一细线图标、48dp 以上触控区域、轻透圆角表面、蓝色选中态、独立的“下一步”主按钮，关闭 / 收起改为图标。整块工具面板仍完全透明，单个按钮半透明；并非完全不占截图像素，仍可点“移位”切到顶部。不是系统材质模糊或苹果原生控件。
3. 保留两步摘录、顶部选区预览、键盘避让、收起恢复和保存反馈，不新增权限或后台屏幕监听。

## 使用

- 在“同步设置”填写同一知识库的服务 URL 和写入 Token，然后在首页点“刷新”。写入 Token 是个人端读写凭证，不是 AI 只读 Token。
- 其他设备必须先上传，安卓才能拉取；没有点击刷新时不会自动订阅远端变动。进入首页会显示本机记录与当前配置的已有缓存。
- 首次拉取包含历史变更，图片较多时需要等待。每次最多处理 2,000 条变更，超过后有提示，可再次刷新继续。列表延续最近 50 条显示上限。
- 本机同 ID 记录优先，尤其不覆盖未上传内容；这不是完整的双向编辑 / 冲突解决。云端更新、删除、恢复会更新“远端独有记录”的缓存显示，不覆盖或删除本机同 ID 记录。

## 数据与安全边界

- 缓存位于应用私有目录，按服务地址和凭证的 SHA-256 标识隔离，不在目录或缓存元数据写入明文 Token。切换配置不会混入前一个知识库；刷新中配置改变会停止提交。
- 每页记录和图片完成后原子写入游标。下载中断不丢掉本机内容；前面完整下载的页仍可查看，下次从已提交游标继续。
- 图片校验大小和 SHA-256，校验图片尺寸。忽略服务端资产 `href`，只向配置的服务构造已知资源路径；不跟随 HTTP 重定向，不向其他主机转发凭证。维持 HTTPS 或私网 / 回环字面 IP HTTP 的原有限制。
- 单页 JSON 上限 8 MiB，单图 16 MiB / 6,400 万像素，映射后的单条元数据 512 KiB；超限或损坏资源会报拉取失败，不推进该页游标。
- 缓存保留完整服务端元数据，不更改记录的 AI 可见性。云端删除会隐藏对应远端记录，但历史缓存文件尚未做安全擦除或容量回收；更换 Token 不自动删除旧缓存。本机文件仍依赖 Android 应用沙箱保护，不宣称端到端加密。
- 本次没有修改或部署线上服务端、迁移数据库或更改 Token。
