# Mnote 1.17.0-test

- 首页记录采用独立纸页卡片：暖白底色、细边框和卡片间留白，记录之间更容易区分。
- 每条记录显示时间与紧凑系统分类；自定义标签使用更小的浅色 `# 标签`，与墨绿系统分类区分。
- 纯截图/纯文字摘录显示“摘录”；想法、待办及其他已有类型保持原记录，不迁移或改写内容。
- Android 移除首页底部截图/随手记操作栏；系统快捷方式仍可使用，可在设置的“快捷方式与权限”配置。
- Android 自定义标签随宽度与系统字号换行；长按多选、筛选、刷新、删除、导出仍使用原有流程。
- Windows 同步卡片和紧凑标签；窄窗口的截图/随手记入口移至侧栏，不再占用列表底部空间。

本版本沿用 Android 测试签名；Windows 为未做发行者签名的 x64 测试安装器。请保存草稿后覆盖安装，不要卸载旧版。安装包和更新清单来自自建服务器，不依赖 GitHub 仓库是否公开。
