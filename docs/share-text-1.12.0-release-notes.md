# Mnote 1.12.0-test · 文字分享预览与原地导出

## 分享管理回看文字和图片

分享卡片现在直接显示“我的想法 / 摘录 / 原文与上下文”摘要及图片预览。点击“展开全部文字”可阅读当次导出的全部文字；Android 长文分页显示、可选中复制，Windows 使用只读滚动阅读框。纯文字分享也可直接预览和展开。

新增文字快照与图片一样，固定在导出时，不受原记录后来编辑或删除影响。文字预览和全文只允许所属账号读取；原来的公开图片链接依旧只能访问图片，不公开文字接口。

重要限制：**旧版分享只保存了图片，没有保存文字快照，无法准确补回历史文字。**旧分享会显示明确提示，不用当前记录冒充历史内容。如需在分享管理中保留文字，请重新选择记录导出。

## 分享管理移至设置

Android 和 Windows 统一使用“设置 → 分享管理”。导出选择界面不再放置分享管理入口。查看历史分享无需先选择待导出的记录；未登录时提示先登录。

## 在记录列表中直接选择、导出

首页“选择导出”和长按记录进入同一套原地多选模式：前者初始不选中任何记录，后者选中被长按的那条。保留当前搜索、类型与标签筛选，可继续勾选、全选当前、删除或取消。

选择完成后点击“导出 Markdown / 导出已选”，直接进入分享确认和系统保存位置选择，不再打开第二个记录选择页。取消确认或文件选择不创建分享；取消后保留原来的勾选，方便继续调整。

只允许当前账号已经同步、未删除且未禁止 AI 导出的记录，最多 100 条。选择中含不可导出的记录时明确提示，不悄悄遗漏。文件写入失败仍尝试撤销刚创建的分享，失败时提示到设置中处理。

## 升级

Capture Server 0.5.0 增加账号鉴权的文字快照接口，不改变数据库结构；旧客户端和已有图片链接兼容。双端 1.12.0-test 从自有服务器更新，Android versionCode 27，沿用原测试签名；Windows 为未签名 x64 测试版。保存草稿后覆盖安装，不要卸载旧版。
