# Mnote 1.18.0-test

- 首页系统分类按实际内容组合显示：同条记录可同时拥有“想法”和“摘录”，不再以单个“批注”标签概括两类内容。
- 旧批注记录只要写了自己的文字，也会显示为“想法”；待办继续保留“待办”，含素材时同时显示“摘录”。仅有素材不会误标为想法。
- 同一卡片上方预览自己的想法，下方以独立浅底引用块预览摘录，标题、颜色和引用边线明确区分。截图保留真实缩略图；没有选中文字时可预览已保存的页面原文。
- “想法”与“摘录”筛选按内容匹配，同一条混合记录能在两个筛选中找到；自定义标签、搜索和长按多选保持原有流程。
- 列表只显示有限行数，详情中的想法、摘录和原文依然完整；不会迁移存储类型、改写正文或新增公开分享。
- Android 和 Windows 同步更新。沿用小标签、纸页卡片，以及系统截图/随手记快捷方式。

Android 沿用原测试签名；Windows 为未做发行者签名的 x64 测试安装器。安装前保存草稿，覆盖安装即可，不要卸载旧版。安装包与更新清单由自建服务器提供，不依赖 GitHub 仓库是否公开。本次不升级服务器，也不迁移记录。
