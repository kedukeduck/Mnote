# Mnote Android 1.14.0-test · 想法优先的自适应分享卡片

## 排版规则

- 勾选“我的想法”时，完整保留原文字、段落、表情和结尾，不摘要、不截断，使用固定的舒适字号。
- 短内容自然收短，二维码跟随内容，不再强行填满 1080 × 1920 画布。
- 略超一屏时先收紧间距和摘录字号，不缩小想法字号；再按模块分配高度。
- 摘录、圈选截图、页面截图按实际内容和优先级分配剩余空间。模块用不完的空间会再分配，不保留空占位。
- 摘录超出上限时优先在段落、句子边界截断，否则在完整显示行内保留安全文字边界；不切开表情组合或英文单词。图片上独立标注“摘录未完整展示”，不冒充原话中的省略号。
- 圈选截图保持完整缩放。页面截图过长时以局部窗口展示，并在图片上标注“页面截图 · 局部预览”。可点击“调整页面位置”，边预览边移动到需要的上下位置。
- 完整想法和所选模块的最低展示空间超过一屏时，自动生成单张长图，不通过删掉想法或勾选模块强行凑成一屏。
- 取消其他模块释放空间后，摘录会重新计算，空间足够就恢复完整展示。所有变化仅影响这次分享，不修改原记录和原截图。

## 预览与保存

预览顶部说明短卡片 / 一屏 / 长图，以及想法完整、摘录部分展示、页面局部等状态。点击图片放大，可按屏幕宽度上下滚动阅读长图。

长图预览和相册图片共用同一份排版。超长 PNG 使用分块绘制、流式压缩，导出的仍是**一张完整图片**，不把预览缩略图当成原图保存。

普通两万字想法的排版已加入测试。异常高的内容（例如大量空行）超过 120000 像素高度或资源不足时会明确失败，不截断后冒充完整图片；原记录保留。极长 PNG 在不同相册、社交软件中的打开和压缩表现仍受这些应用限制。

二维码继续只承载用户明确选择的原文与来源，不因为摘录截断而自动公开完整摘录或想法；不会显示不实的“扫码查看完整想法”。已有分享管理和撤销行为不变。
