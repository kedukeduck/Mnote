# Android 1.22.2-test

- 修复部分抖音视频的低码率版本只有画面、没有音轨，导致下载成功但文字稿解析失败的问题。服务端现在会先验证本地音频解码，再尝试同一视频的正常播放版本。
- 修复完整分享文案含 Markdown 链接、同一链接重复出现时无法解析的问题；多个不同链接仍需分别处理，签名参数保持不变。
- 解析失败时展示具体原因和安全错误标识，区分无可用音频、媒体解码失败、语音识别失败、任务过期、平台限制和网络超时。

已有失败任务不会因刷新而自动重跑。请点「更换链接重新解析」，重新粘贴分享链接并确认本次声明。已有摘录、想法、图片和标签不会被覆盖。

音视频处理仍取决于公开访问条件、文件大小和时长；不会绕过登录、验证码、DRM 或其他平台访问限制。所有识别内容均需人工校对。
