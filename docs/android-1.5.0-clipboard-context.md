# Android 1.5.0-test：截图入口与剪贴板摘录分开

包名 `com.codex.mnote`，versionCode 18。沿用调试 / 测试签名，保存未完成的草稿后覆盖安装，不要卸载旧版。

## 使用方式

- **单次摘录**：直接截图，继续使用原有“圈选 / 批注 → 下一步 → 想法 → 保存”流程。即使已经选中文字或剪贴板有内容，也不读取它们。
- **随手记**：默认只写想法或 TODO，仍支持手动添加来源链接。无需无障碍权限。
- 在随手记主动开启 **摘录剪贴板第一条**，读取一次系统当前剪贴板的第一个条目。摘录与想法分开显示，可以编辑。不访问系统输入法的剪贴板历史；第一条不是可用文字 / HTTP(S) 链接时提示失败，不继续找第二条，不解析图片、文件或任意内容提供器 URI。
- 如需背景，可再点击 **读取页面文字** 或 **保存页面截图**，二选一。也可以都不点，只保存摘录和想法。上下文可预览、编辑文字或移除。关闭剪贴板摘录会清除本次未保存的摘录和上下文，保留想法及手填链接。
- 页面上下文需要已启用并连接的 Mnote 无障碍服务；截图还需 Android 11+。读取失败保留想法与摘录，并给出提示，不会自动改为截图。可到首页“快捷方式与权限设置”启用服务后，回到所需外部页面重新打开随手记。

如果使用系统文字菜单里的 Mnote 或系统分享，仍由已有的文字 / 分享入口处理；这次仅取消单次摘录磁贴的自动选区扫描。

## 当前页面不等于剪贴板原始出处

剪贴板可能来自更早的页面，因此附加的是**随手记下方当前外部页面的上下文**，不是自动还原复制时的出处。从 Mnote 首页打开随手记时，下方仍是 Mnote，不能把它当作外部原文；需要返回目标应用后从快捷设置磁贴打开。

附加前临时收起键盘，并将随手记缩为不可触摸的 1×1 透明过渡窗口，确认外部来源后读取 / 截图，再恢复编辑界面。只跳过本次可识别的过渡窗口，未知窗口或其他 Mnote 页面会停止读取。失焦、离开前台、取消、超时、账号变化或截图前后窗口 / 已识别 URL 不一致时丢弃本次结果。不会自动点击、滚动或导航来源应用，也不会绕过安全截图限制。页面可以自行更新，窗口检查不能证明像素完全未变；保存前请核对预览。

“读取页面文字”仅包含应用向无障碍暴露的可见、非密码、非可编辑文字，可能含工具栏等界面内容、重复节点文字，也可能不提供正文；不承诺文章全文。最多 512 个节点、1024 次子节点查询、750 毫秒查询间预算、4 万 UTF-16 字符；达到限制即失败，不默默截断。无法中断单次正在执行的系统查询。本版没有 OCR、网页抓取或强制读取不可访问内容。

## 数据与同步

- 想法保存在 `comment`；摘录保存在 `sourceText`，采集方式为 `clipboard`；可读原文保存在 `captureContext.text.full_text`。
- 文字上下文标记 `origin=accessibility_page`、`extent=visible_accessibility_text`、`relation_to_quote=unverified`，并保留该页面可识别的包名 / 浏览器 URL。文字可在保存前编辑；此处的 origin 表示获取渠道，不表示内容未经用户修改。
- 页面截图使用已有图片及完整上下文资产，`captureContext.image.purpose=page_context`，`relation_to_quote=unverified`，`selection_meaning=full_viewport_not_quote_location`。全幅范围只表示保存了整页，**不是推断文字在截图中的位置**。详情页不会显示误导性的圈选框或圈选 / 全图切换。
- 摘录保留第一条文字（含首尾空白），最多 10 万 UTF-16 字符；想法最多 2 万，原文最多 4 万。超长拒绝保存，不静默截断。
- 沿用既有本地持久化、列表即时更新、当前账号自动同步与拉取、已保存记录编辑 / 删除和 AI 权限。保存前检查账号归属，保存失败保留编辑内容，成功 / 失败都有 Toast。
- 未保存截图仅存应用私有草稿目录，取消、移除或关闭摘录时删除，保存成功移入正式记录后移除草稿。旋转重建保留本次输入 / 已选上下文，不再次读取剪贴板。不是系统级剪贴板管理器，不提供草稿历史或安全擦除历史版本。
- 不更换服务器地址或账号机制，不修改线上服务器。

## 验证与手机验收

自动化覆盖默认零剪贴板 / 页面读取、第一条语义、不解析内容 URI、空 / 超长输入、明确同意、独立想法 / 摘录 / 原文 / 整页图片、读取失败不截图、失焦取消、超时、窗口变化、草稿清理、旋转重建、账号隔离、保存提示，以及截图磁贴不调用选区扫描。真实 Android View 的 Skia 预览覆盖默认页面、素材页面和键盘大小视口；它们不是手机实机截图。

覆盖安装后建议在手机上检查：

1. 在 Chrome 或其他应用复制文字，点“单次摘录”，应始终截图。
2. 点“随手记”，默认不附加摘录；开启开关后应显示刚复制的第一条文字。
3. 不附加上下文，输入想法并保存；首页应立即显示，并按账号同步。
4. 回到外部页面再打开随手记，分别尝试页面文字与页面截图；确认预览不包含随手记或键盘。
5. 移除上下文 / 关闭摘录后保存，检查详情无被移除素材。
6. 旋转、唤起键盘、取消、读取不支持的应用和断网保存，确认输入仍可见、内容未丢失且有结果提示。

厂商剪贴板访问、键盘收起及透明任务栈行为仍需手机实测。本次不使用个人账号向线上服务写入测试数据。
