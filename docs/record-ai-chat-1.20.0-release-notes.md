# Mnote 1.20.0-test · 围绕一条记录，继续聊聊

## 新功能

- 随手记、截图批注保存时可选择「保存并聊天」；先保存笔记，再进入对话，不会自动调用模型。
- 单条记录详情可开始讨论、继续历史会话，或围绕同一条记录新建独立对话。
- AI 使用本次确认的资料副本：想法、摘录、原文、截图及来源信息可以分别选择。截图以实际图像发送，不需要公开图片链接。
- 支持多轮回复、流式展示、停止生成、保留未完成回复和无重复问题重试。失败不会抹掉已保存的笔记。
- 设置新增「AI 模型配置」及全部聊天历史；支持多个 OpenAI-compatible Chat Completions HTTPS 服务配置和连接测试。
- 聊天记录按 Mnote 账号同步。详情页只显示本条记录的会话，全局历史可搜索、重命名、删除。
- 列表显示已完成 AI 对话数量，并可筛选「已聊过／尚未聊过」，可与原有分类、标签筛选组合。

## 使用方法与数据说明

1. 在每台设备的设置中填写 API 服务地址、模型名称和 API Key；使用截图时需启用图片并确认模型支持。
2. 从记录详情进入 AI 对话，选择资料范围，确认发送目标和授权后提问。
3. 需要新版记录资料或另一模型时，新开一个对话。旧会话保留原始资料副本，不会悄悄替换上下文。

模型配置及密钥仅保存在当前设备（Android Keystore / Windows DPAPI），不随账号同步。聊天消息与选中的资料副本会保存到自己的 Mnote 同步服务器，并非端到端加密；模型服务商的费用和保留规则由该服务决定。首次使用、跨设备首次续聊或权限改变时需确认授权。

删除原记录也删除其聊天和资料副本；恢复笔记不会恢复聊天。单独删除聊天不影响原记录。删除无法撤回已经发送到模型服务商的数据。两个设备同时修改时保留本机冲突副本，不覆盖另一端回复。

第一版不自动访问其他记录、执行工具或修改笔记，不提供全库问答。超出上下文/会话容量时明确提示，需减少资料或新开对话，不会静默截断。已登录账号续聊前需要成功同步，以避免双端重复生成。

## 安装说明

Android 1.20.0-test（versionCode 36），Windows 1.20.0-test，配套服务端 0.9.0。
请覆盖安装，不要卸载旧版。Android 沿用已有测试签名；Windows 安装包没有商业代码签名。实际服务商兼容性取决于其接口与模型能力。
