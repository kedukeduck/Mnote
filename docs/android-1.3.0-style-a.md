# Mnote Android 1.3.0-test：A「轻盈极简」

## 范围

按用户选定的 A 方案统一 Android 原生 UI，不修改账号协议、生产服务端、无障碍选区读取策略或记录格式。概念图用于视觉方向，不加入假 AI 聊天、标签等未实现入口。

覆盖页面：记录首页、随手记、文字摘录、图片编辑、系统级悬浮圈选与想法编辑、账号登录/激活/退出、本机记录导入、旧同步设置页。

覆盖应用弹窗：记录详情、完整截图回顾、删除确认、放弃编辑、来源与权限说明、过渡页错误、原文补充、账号退出/导入、同步确认。系统权限页、系统键盘、系统分享菜单仍由 Android/手机厂商控制，不能强行改成应用主题。

## 统一视觉规则

- 背景：冷白灰 #F7F8FA；卡片/输入区域：白色。
- 正文：石墨色 #202430；辅助文字：#687184；强调色：#5064E8。
- 细线 #E4E8F0，卡片 18dp 圆角、输入框/普通按钮 14dp、对话框 24dp。
- 标题约 30–32sp，编辑栏标题 17sp，正文/输入 15–19sp，辅助说明 12–14sp。
- 普通页面与服务悬浮层共享颜色资源；对话框统一使用 Theme.Mnote.Dialog，透明过渡 Activity 只调整对话框主题，不更改透明捕获窗口的行为。
- 删除入口与删除确认使用危险色。捕获成功的短暂悬浮提示保留透传触摸，采用统一石墨底色。

## 首页

固定底部“随手记 / 摘录”操作区，列表独立滚动；无障碍与快捷方式说明收进“快捷方式与权限设置”，里面仍可进入来源诊断。

支持按正文、摘录文字、来源 URL 搜索；支持全部/摘录/想法/待办筛选。“摘录”按存在截图或摘录文字判断，“想法/待办”按记录类型判断，因此一条记录可以同时属于摘录和想法。清空搜索恢复列表，空结果有明确提示。搜索仅针对已保存/已拉取内容，不向第三方发送关键词。

保留手动刷新、保存后即时更新和账号同步。筛选前读取完整本机及已拉取列表，筛选后最多显示 50 条（沿用现有渲染上限）；计数显示匹配数量与总数量。快速切换条件时跳过失效的缩略图解码任务。

## 编辑与账号

截图与摘录内容优先呈现，“我的想法”独立标识。纯文字随手记继续把主要空间留给输入；悬浮编辑仍先圈选、再写想法。圈选阶段保持透明工具背景，不用实心面板覆盖截图。保留 IME 避让、滚动、移位、缩小和取消操作。

登录页补齐返回、字段标签和纵向间距；首次激活码标签与输入框共同显隐。密码/激活码不保存、不参与自动填充，账号页继续禁止截图。

新增首页搜索/筛选、空状态、小屏大字体底部操作区、详情/删除弹窗、透明过渡页主题测试。继续运行原有保存/同步/选区读取、键盘、小屏、透明工具等回归测试。

UI 预览由 Robolectric/Skia 渲染真实 Android View，不是手机实机截图。尚需用户设备验收输入法、系统缩放与厂商窗口差异。
