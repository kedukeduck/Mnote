# Android 1.6.0-test：标签、长文阅读与稳定性

包名 `com.codex.mnote`，versionCode 20。沿用既有调试 / 测试证书，请先保存草稿，再覆盖安装，不要卸载旧版。

## 标签如何使用

- 随手记、截图悬浮编辑器、分享 / 处理文字 / 图片入口均可添加标签。输入例如 `灵感，工作，待读`，英文逗号、中文逗号、分号或换行均可分隔。旧版直接写想法入口的标签按钮位于顶部。
- 一条记录可以属于多个标签；不填则归入“未分类”。编辑已有记录可以补充、修改或清空标签，不改变记录 ID、截图、圈选坐标和原文证据。
- 每条记录最多 20 个标签，每个最多 32 个 UTF-16 字符；去首尾空白和开头的一个 `#`，大小写不敏感去重并保留首次写法。不默默截断超限标签。
- 首页“标签 · 全部”选择具体标签或“未分类”；可叠加摘录 / 想法 / TODO 类型和关键词搜索。标签文字也参与本机搜索。筛选范围包括所有已拉取、本机可用的记录；每批展示 50 条，“显示更多记录”可继续查看。
- 筛选随屏幕旋转保留，切换账号时重置，不使用其他账号的标签。离线保存后，标签与记录一起按现有账号同步；未登录的记录仍只在本机，不新增上传权限或自动迁移。

## 长文与页面读取

- 随手记的想法、剪贴板摘录、页面原文，以及已有记录编辑页的三个文字区，都支持内部滚动和“已保留 N 字 · 展开编辑”。展开后使用独立的全屏滚动输入区，键盘打开时重新分配空间，提供“到文末”。
- 展开编辑即时回填原来的编辑器，旋转时跟随原有草稿保留。点击“完成”只是返回编辑器，仍需点击记录页“保存”才持久化。关闭或取消整条未保存记录仍按原有确认流程处理。
- 无障碍读取由广度优先改为按嵌套段落顺序读取；可见、非敏感、非输入的叶节点未提供文字时，尝试其无障碍描述。不重复读取父容器描述作为段落。
- **原文是本次应用开放的可访问页面内容，不保证文章全文。** 不自动滚动来源应用、不爬取链接、不 OCR、不读取隐藏 / 密码 / 编辑框 / 系统敏感内容。原有节点、查询时间和字符预算保持不变；超限不静默保存截断内容。需要屏外全文时，可由用户复制全文后在原文编辑器补充。
- “单次摘录”仍只截图，“随手记”的剪贴板摘录与页面上下文仍独立选择。

## 闪退风险与本机诊断

仍未取得用户手机的崩溃堆栈，因此不能承诺该设备的偶发闪退已被完整复现或彻底消除。本次可确认的改动：

1. 首页换列表 / 筛选、详情关闭、截图编辑器切换预览或关闭时，不再手动回收交给 UI 绘制的位图；由 GC 在最后一帧使用结束后回收。未绑定 UI 的后台临时图片仍可及时回收。
2. 页面文字在编辑根视图仍为 `GONE` 时填入，随后恢复正常窗口；继续保留后台读取、取消、超时和迟到结果校验。
3. 截图写入的内存分配失败走失败提示、保留编辑内容路径，不直接让保存线程异常退出。
4. 应用记录最近一次未捕获 Java 异常的本机摘要，之后仍调用 Android 原有异常处理器，不吞掉崩溃。只记录版本、时间、Android API、异常类、有限堆栈中的类 / 方法 / 行号；不记录异常消息、线程名、源文件名、笔记、截图、来源 URL 或凭证。Android 11+ 另展示最多 3 条系统退出原因代码 / 状态 / 时间，不读取系统 trace 或 description。

如仍闪退：重新打开 Mnote → 首页“快捷方式与权限设置” → “本机异常诊断” → “复制诊断”，连同发生步骤、手机型号、Android 版本提供给开发者。诊断默认只存本机私有文件 `last-crash.txt`，下一次异常覆盖，未开启备份、不上传。Java 摘要为空不代表没有崩溃，原生崩溃 / 系统杀进程等可能只有系统退出原因。

## 数据兼容与验证范围

Android 本地 `record.json.tags` 和同步顶层 `tags` 均为字符串数组，旧记录缺省为空。清空标签明确上传 `[]`，避免被 `canonicalBase` 中旧标签覆盖。标签纳入编辑冲突指纹，旧编辑调用保留已有标签；沿用账号、修订号和 copy-on-write 提交策略。

现有服务端保留扩展元数据，无需数据库迁移或线上服务修改。测试覆盖创建 → 上传元数据 → 拉取 → 编辑 / 清空 → 再上传；Windows / 浏览器客户端本次未增加标签编辑或筛选界面。

本版使用 Robolectric / 原生 Skia 做自动回归和布局检查，不等同于真机测试。
