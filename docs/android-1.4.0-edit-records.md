# Android 1.4.0-test：编辑已保存记录

包名 `com.codex.mnote`，versionCode 17，沿用调试 / 测试签名。先保存编辑中的内容，然后覆盖安装，不要卸载旧版。

## 使用

打开记录详情，点击右上角“编辑”，可以分别修改：

- 我的想法 / 评论 / 待办内容，最多 2 万个 UTF-16 字符。
- 摘录文字，最多 10 万个 UTF-16 字符。
- 保留的原文，最多 4 万个 UTF-16 字符。可以补充，也可以清空，将其从当前记录的原文栏移除。

点击保存更新同一条记录，ID、创建时间、来源链接、账号归属和 AI 权限不变，不生成重复记录。保存成功有 Toast，并返回更新后的详情。详情右上角改为主要操作“编辑”；删除移到阅读页下方，仍需确认。

编辑页延续 A「轻盈极简」主题。三个文字输入区独立呈现，页面可滚动，键盘打开后仍可访问输入框和顶部保存按钮。输入过长或保存失败不会截断内容、关闭页面或清空输入。取消 / 返回时，存在未保存修改则要求确认；旋转重建保留输入。

这版编辑的是文字。截图、完整截图及圈选区域不会被重画、替换或重新裁切；编辑截图上可见的像素文字 / 重新圈选不在本次范围内。

## 保存与同步

- 支持本机记录，以及从其他设备拉取的账号记录。后者编辑后进入当前账号的本机待同步列表，远端缓存保持只读。
- 本机采用写入新版本、最后原子切换指针的方式发布修改。写入失败时旧记录仍完整；保存后发送列表更新通知并调度账号同步。
- 同步与编辑使用相同账号锁，避免上传途中被更新后误标为已同步；保存前校验账号、记录是否被删除及正在编辑的三个字段是否已发生变化。
- 使用已有服务端 `base_revision` 协议更新同一 ID；未修改的截图不重新上传，也不改变原有云端资产角色。未首次上传的图片记录仍完整上传图片。
- 云端返回版本冲突时，不覆盖新版本，也不丢弃本机修改；其他记录继续同步。首页和记录状态显示冲突提示。本版不提供自动合并或强制覆盖入口，冲突需要核对两份内容后另行处理。
- 不修改线上服务端，不更换账号与同步地址。服务端只新增本地协议回归测试。

## 内容来源与隐私

只修改想法时，原来的摘录、原文和定位信息保持不变。修改摘录或原文时，重新计算其对应位置；重复或无法匹配时不伪造精确位置。原文手动修改标记为 `user_edited`，摘录手动修改同时更新 `exact_text.delivered_by` 和来源说明，既有浏览器选择器标记为需要重新验证。

从云端记录继续编辑时，保留 OCR、来源附加字段、原有批注、AI 权限等非编辑内容。附加元数据过大或无法安全读取时拒绝保存，保留输入，不以丢弃字段的方式降级。

本机旧版本及旧远端缓存仍保留用于写入保护；清空当前原文栏不等于安全擦除历史文件。本版未新增历史版本管理或存储清理入口。文件布局增加 `current.json` 与 `edits/<version>/`，不建议降级旧 APK 后读取本机编辑版本。
